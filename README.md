# Temperature Dashboard – Power BI
## Project Overview
This Power BI dashboard provides an in-depth analysis of temperature variations across different cities over multiple years and months. The aim is to help users understand seasonal trends, identify extreme weather patterns, and compare climates across geographic locations.

## Scope of the Dashboard
- Cities Analyzed: Multiple 
- Time Period Covered: Multiple years and months

- Key Metrics:

  - Average Monthly Temperature

  - Maximum & Minimum Temperatures

  - Yearly Temperature Trends

  - Location-wise Comparison

## Data Source
- The data used in this dashboard was sourced from:

  - kaggle 

- Data was cleaned and transformed using Power Query Editor in Power BI.

## Key Features
- Interactive Filters: Allows users to filter by city, year, and month.

- Trend Analysis: Line charts for year-wise temperature trends.

- Location Comparison: Bar and map visuals showing comparative analysis.

- Extreme Conditions: Highlights of the hottest and coldest recorded months.

## Tools & Technologies Used
- Power BI Desktop

- Power Query Editor

- DAX (Data Analysis Expressions)


## Insights Derived
- Northern cities show greater seasonal temperature changes.

- Coastal cities tend to have more stable temperatures.

- Year-to-year variability reflects broader climate trends.
